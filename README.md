# Real Estate Landing Page

A modern and responsive real estate landing page built using **HTML**, **CSS**, and **JavaScript**. The project includes luxury property sections, amenities, master plan, image sliders, specifications, and a fully responsive footer design.

## Features

* Responsive Design
* Modern UI Layout
* Hero Section
* Amenities Section
* Interactive Image Slider
* Master Plan Section
* Specifications Accordion
* Premium Footer Design
* Mobile Friendly
* Smooth Animations

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
